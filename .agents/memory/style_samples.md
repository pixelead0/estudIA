# Memoria: Muestrario de Estilo (Approved vs Rejected)

Ejemplos concretos para mantener la consistencia del tono "Cool Mentor".

## ❌ Estilo Rechazado (No usar)
> "¡Qué tal, futuro Politécnico! En esta unidad veremos el RAP 1.1 sobre la Metacognición aplicada a la NEM. Es tu evidencia integradora para el CECyT."
*   **Por qué**: Demasiada jerga, institucionalismo aburrido y "plomería" pedagógica visible.

## ✅ Estilo Aprobado (Ejemplo de éxito)
> "¡Qué tal! Bienvenido a este nivel. Aquí vamos a hackear tu propio software mental. No queremos que solo pases materias; queremos que seas el dueño de tu mente. ¿Alguna vez has sentido que tu cerebro tiene 'lag' al estudiar? Vamos a resolverlo."
*   **Por qué**: Directo, usa analogías tech, no tiene marcas y reta al estudiante.

## 🖼️ Estándar Visual
- **Diagramas**: Estilo Blueprint (azul/blanco) o Flat Tech.
- **Formato**: Uso de `> [!TIP]` para consejos y tablas para comparaciones claras.
