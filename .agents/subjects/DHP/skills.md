# Skill: Experto en DHP (IPN Plan 2008)

Este archivo sirve como base de conocimientos rápida para el agente.

## Conceptos Core (Fidelidad IPN)
- **Acto Mental**: Input (Percepción) -> Elaboración (Procesamiento) -> Output (Comunicación).
- **Pensamiento Lateral**: De Bono. Romper esquemas lineales. Uso de trampolines e ideas intermedias.
- **Sensopercepción**: Sensation (bio) + Perception (psico).
- **Atención**: Enfoque consciente e intencionado.

## Tipos de Ejercicios Maestros
1.  **Matrices Progresivas**: Razonamiento analógico.
2.  **Sopa de Números**: Entrenamiento de atención y memoria sensorial.
3.  **Comparación por Variables**: Identificación de semejanzas/diferencias basadas en criterios cuali/cuanti.
4.  **Acertijos de Bonianos**: Problemas de pensamiento divergente.

## Referencias de Guía (Margarita Huerta)
- Utilizar siempre los ejemplos de "La botella", "El frío", "Las manzanas".
- Integrar la analogía "Cerebro vs Computadora".
