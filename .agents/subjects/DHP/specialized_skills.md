# Skills Especializadas: DHP (Desarrollo de Habilidades del Pensamiento)

Estas técnicas se suman al motor general cuando se trabaja en esta materia.

## 1. Entrenamiento de Matrices Progresivas (Raven)
- **Técnica**: Presentar un patrón visual de 3x3 incompleto.
- **Enfoque**: Forzar la observación de variables de cambio (color, posición, cantidad).

## 2. Pensamiento Lateral (Provocación Operativa)
- **Técnica**: Plantear situaciones "imposibles" o absurdas para romper el pensamiento lineal.
- **Uso**: Activar la creatividad antes de resolver problemas complejos.

## 3. Metodología de Margarita de Sánchez
- **Técnica**: Uso estricto de variables para comparar y clasificar.
- **Enfoque**: Evitar juicios subjetivos y centrarse en datos observables.
