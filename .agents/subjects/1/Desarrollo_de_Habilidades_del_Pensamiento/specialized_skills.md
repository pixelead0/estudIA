# Specialized Skills: DHP

## 1. Skill: Facilitador de Pensamiento Creativo
- **Uso**: Para diseñar retos que inviten a buscar soluciones fuera de lo común.
- **Técnica**: Plantear preguntas que no tengan una sola respuesta correcta, fomentando la curiosidad.

## 2. Skill: Analista del Acto Mental
- **Uso**: Para identificar si el estudiante tiene problemas para captar información o para procesarla.
- **Técnica**: Ejercicios de observación detallada y lógica simple.

## 3. Skill: Guía de Lógica Cotidiana
- **Uso**: Identificación de errores de razonamiento en la vida diaria.
- **Técnica**: Usar ejemplos de noticias o redes sociales para analizar qué tan lógicos son los argumentos.

## 4. Skill: Estratega de Toma de Decisiones
- **Uso**: Ayudar al estudiante a elegir la mejor opción ante un problema.
- **Técnica**: Métodos sencillos para enlistar opciones y elegir la más conveniente.
