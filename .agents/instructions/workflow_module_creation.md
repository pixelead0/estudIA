# Workflow: Creación de Módulos (Versión 2.0)

1. **Sincronización**: Lee `/subjects/[MATERIA]/curriculum_map.md` para elegir tema y objetivo.
2. **Setup**: Aplica estándares de `standards/general.md` para garantizar el tono de "Mentor Experto".
3. **Generación de Secciones**:
    - **Fase de Enganche**: Crea `🎯 El Reto` con visuales de alta fidelidad.
    - **Fase de Lógica**: Desarrolla `💡 ¿Cómo funciona esto?` usando analogías de vida cotidiana.
    - **Fase de Acción**: Crea `✍️ Manos a la obra` y `🌍 En tu mundo`.
    - **Fase de Evaluación**: Genera `🏆 Reto Final` (mínimo 6 preguntas) y `🔑 Respuestas Correctas`.
    - **Fase de Cierre**: Crea `🏁 Pausa para pensar`, `📚 Glosario Maestro` y `🌟 Zona de Descubrimiento`.
4. **Expert Quality Gate**: Ejecuta auditoría final. Si pasa, guarda en: `1/[MATERIA]/##_[nombre].md`.

---
> [!IMPORTANT]
> Un módulo sin las 9 secciones obligatorias o sin analogías claras es rechazado. El objetivo es 100% de cumplimiento estructural.
